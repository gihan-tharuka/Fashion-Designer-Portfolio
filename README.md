# Fashion-Designer-Portfolio

A front-end only Next.js digital portfolio for the LUMENÉ contemporary womenswear collection.

## Tech Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Front end only, deployable on Vercel

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Image Placeholders

Add final portfolio imagery to `public/images/` using these paths:

- `/images/lumene-hero.jpg`
- `/images/moodboard.jpg`
- `/images/fabric-board.jpg`
- `/images/design-development.jpg`
- `/images/final-look-1.jpg`
- `/images/final-look-2.jpg`
- `/images/textile-sample.jpg`

If an image is missing, the site displays an editorial placeholder block instead of a broken image.
